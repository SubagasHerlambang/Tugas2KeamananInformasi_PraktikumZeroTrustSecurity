# Naskah Video Demo SecureCampus (target ± 8 menit 30 detik)

> **Status: naskah saja — video BELUM direkam.** Naskah hanya menunjuk perintah, layar, dan kode yang benar-benar ada di repo dan sudah dijalankan pada pengujian. Jangan menampilkan token aktif atau secret gateway di rekaman: gunakan perintah dekode klaim di bawah (mencetak klaim saja, bukan token) dan jangan membuka `.env` secara utuh.
> Persiapan sebelum rekam: `npm run setup:force` (menyiapkan DB seed bersih), 4 terminal (A: `npm start` atau tiga terminal untuk tiap service; B: perintah demo; C: editor kode; D: opsional browser frontend `npm run frontend:dev`). Nomor baris di bawah adalah perkiraan; cari nama fungsinya bila bergeser.

Variabel bantu di terminal B (password demo adalah kredensial lokal fiktif):
```bash
B=http://127.0.0.1:3000; PW='SecureCampus-Demo-2026'
login(){ curl -s -X POST $B/auth/login -H 'Content-Type: application/json' -H "X-Device-ID: $2" -d "{\"username\":\"$1\",\"password\":\"$PW\"}"; }
tok(){ node -pe 'JSON.parse(require("fs").readFileSync(0)).access_token'; }
claims(){ node -e 'console.log(JSON.parse(Buffer.from(process.argv[1].split(".")[1],"base64url")))' "$1"; }
```
